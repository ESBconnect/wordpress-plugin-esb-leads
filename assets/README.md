# Assets Directory

This directory contains images and other assets for the ESBConnect Leads Collector plugin.

## Required Images

### elementor-setup-example.png
- **Purpose**: Shows how to add the `client_account_id` field in Elementor form builder
- **Content**: Screenshot of Elementor form builder with:
  - Hidden field type selected
  - Field name set to `client_account_id`
  - Default value set to a sample client account ID
- **Dimensions**: Recommended 800x600px or similar
- **Format**: PNG with transparent background preferred

## Image Guidelines

1. **Clear and readable**: Ensure text and UI elements are clearly visible
2. **Annotated**: Add arrows or highlights to point out the important fields
3. **Professional**: Use clean, modern screenshots
4. **Consistent**: Match WordPress admin styling if possible

## Usage

The plugin will automatically load images from this directory when displaying the settings page.
